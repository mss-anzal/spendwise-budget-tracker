# SpendWise Budget Tracker

## Project Description

SpendWise is a personal budget tracking web application designed to help users record expenses, monitor their spending, and understand their remaining budget.

The application provides a simple and user-friendly dashboard for managing personal finances.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Netlify

## Deployment Process Summary

1. Reviewed and organized the SpendWise project files.
2. Ensured that the HTML, CSS, and JavaScript files were correctly linked.
3. Uploaded and pushed the project files to a public GitHub repository.
4. Connected the GitHub repository to Netlify.
5. Configured the deployment settings, including the base directory and publish directory.
6. Deployed the application to Netlify.
7. Obtained the live Netlify website URL.
8. Tested the deployed application to check that its pages, styles, scripts, and functionality loaded correctly.
9. Connected GitHub to Netlify for continuous deployment.
10. Made a change to the project, pushed it to GitHub, and verified that Netlify automatically deployed the updated version.

## Challenges Encountered During Deployment

One challenge was understanding the deployment configuration, particularly the base directory, build command, publish directory, and functions directory.

Another challenge was ensuring that the README contained all the required deployment information and that the HTML markup was clean and properly formatted.

These challenges were addressed by using the appropriate deployment settings for a plain HTML, CSS, and JavaScript project and reviewing the project files before publishing.

## JavaScript Concepts Used

- **Decision Making:** Used if, else if, and else statements to provide budget feedback.
- **Arrays:** Used an expenses array to store expense records.
- **Loops:** Used for...of loops to process expenses.
- **DOM Manipulation:** Used JavaScript to dynamically update dashboard information and transaction records.
- **Event Listeners:** Used form submission and click events to add and delete expenses.
